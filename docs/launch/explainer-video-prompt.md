## What unity-kit is
A free, MIT-licensed plugin for Claude Code (Anthropic's coding agent) that adds guardrails for Unity 6 projects. It stops the mistakes an AI agent makes most often in Unity, and won't let Claude finish a turn while the project is broken. It doesn't drive the Unity Editor; it runs alongside tools that do.

## Audience and tone
Unity developers who already use or are curious about AI coding agents. Calm, precise, slightly dry. Show, don't hype: no "revolutionary", no exploding particles, no stock-footage people. Think a well-made developer-tool launch video: terminal windows, file trees, code, and clean diagrams.

## Visual system
- Dark background (near-black, slightly blue, e.g. #0E1117), off-white text (#E6EDF3), ONE accent color for "the kit acting" (a warm amber, e.g. #F5A524). Use a muted red (#F85149) only for errors and a muted green (#3FB950) only for "clean/pass".
- Typography: a geometric sans for titles (Inter or similar), a monospace for code, paths and commands (JetBrains Mono or similar). Titles should read at a glance; never more than ~8 words on screen at once outside code.
- Recurring elements: a stylised terminal window (Claude Code session), a stylised Unity Project-window file tree, and a stylised Console panel. Build these as simple flat UI shapes, not screenshots.
- Do NOT use the Unity logo, the Anthropic or Claude logos, or any real product screenshots. Refer to them in words only.
- Motion: snappy ease-out (about 200–300 ms) for UI elements, slower eases for camera moves. Elements enter with short slide+fade; no bounces. Keep the camera mostly still; use one or two slow push-ins for emphasis.
- Burn in captions of the voice-over at the bottom (two lines max, monospace for code words like `.meta`), using the "Caption" text from the script (not the spoken text), synced to the clip timings.
